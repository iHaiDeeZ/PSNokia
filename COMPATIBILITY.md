# PSNokia compatibility

Games tested on a real PS4. Tell us how other games run by opening an issue.

## What the tags mean

| Tag | Meaning |
|---|---|
| ![Playable](https://img.shields.io/badge/Playable-22c55e?style=for-the-badge) | Plays from start to finish without problems that get in the way |
| ![Ingame](https://img.shields.io/badge/Ingame-f97316?style=for-the-badge) | Gets into the game, but has problems that spoil it or stop you finishing |
| ![Intro](https://img.shields.io/badge/Intro-c2410c?style=for-the-badge) | Shows its intro or menus, but you can't start playing |
| ![Loadable](https://img.shields.io/badge/Loadable-dc2626?style=for-the-badge) | Opens, but stays on a black screen or freezes before showing anything |
| ![Nothing](https://img.shields.io/badge/Nothing-111111?style=for-the-badge) | Doesn't start at all |

## Not supported

N-Gage games (such as Crash Nitro Kart) are not Java games: they are
programs for the phone's own Symbian system, so PSNokia can't run them.
